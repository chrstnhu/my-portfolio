## 🎯 About

This portfolio serves as my digital resume and showcase. It highlights my technical background, development skills, and a comprehensive list of projects ranging from web applications (like **TimeTool** and **ft_transcendence**) to low-level programming and system administration projects (like **cub3D**, **minishell**, and **NetPractice**).

The site features a modular JavaScript architecture, smooth animations, and a clean user experience across devices.

---

## ✨ Features

- **Dynamic Sections:** Dedicated views for Home, About Me, Skills, Projects, and Contact.
- **Project Showcase:** Highlights a wide variety of works with visual previews (C/C++ projects, web development, Docker, etc.).
- **Skills Grid:** Interactive display of technical proficiencies, tools, and software.
- **Animations:** Engaging visual transitions and interactive elements powered by custom JavaScript.
- **Multilingual Support:** Translation handler (`translations.js`) for seamless language switching.
- **Responsive Design:** Optimized layout for desktop, tablet, and mobile browsers.

- **Scripting:** Vanilla JavaScript (ES Modules)
